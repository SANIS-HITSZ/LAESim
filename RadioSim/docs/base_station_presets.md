# 低空基站预设与参数依据

## 1. 使用边界

国内目前没有一张由所有运营商和设备商共同采用、同时固定频率、带宽、功率、站高、阵列和感知波形的“无人机低空基站标准参数表”。本工程因此把标准与工程假设分开保存：政策和 3GPP 文档用于确定技术边界，公开试点用于说明可行路线，未公开的完整射频与部署数值使用可复现的仿真代理值。

所有预设都可以编辑。编辑后配置的 `preset_id` 变为 `custom`，同时保留 `source_preset_id` 和 `modified_fields`，从而知道它从哪个预设演变而来。

## 2. 证据与参数状态

| 字段 | 可选值 | 含义 |
| --- | --- | --- |
| `source_evidence_level` | A | 国家部委、3GPP或标准组织正式文件 |
|  | B | 运营商或设备商官方网站案例与产品资料 |
|  | C | 论文、招投标、新闻或二手资料 |
|  | D | 缺少公开来源的经验参数 |
| `parameter_status` | `public_verified` | 当前数值已由公开原始资料核验 |
|  | `trial_specific` | 仅适用于来源试点及其测试条件 |
|  | `simulation_proxy` | 为可复现实验选择的工程代理值，需后续标定 |
|  | `unknown` | 尚未确认 |

一个预设即使引用 A 或 B 级来源，只要功率、阵列、站高或密度没有被同一来源完整公开，完整参数组合仍标为 `simulation_proxy`。

## 3. 当前低空预设

| 预设 | 中心频率 | 带宽 | 功率 | 站高 | 密度 | 主要用途 | 来源等级 | 参数状态 |
| --- | ---: | ---: | ---: | ---: | ---: | --- | --- | --- |
| 低频广域通信站 | 700 MHz | 20 MHz | 49 dBm/sector | 35 m AGL | 2站/km2 | 郊区航线、物流、应急遥测 | A | simulation_proxy |
| Sub-6 GHz低空宏站 | 3.5 GHz | 100 MHz | 49 dBm/sector | 25 m AGL | 5站/km2 | 普通城区、公网低空增强 | A | simulation_proxy |
| 4.9 GHz通感一体实验站 | 4.9 GHz | 100 MHz | 49 dBm/sector | 25 m AGL | 10站/km2 | 景区、重点设施、港口、低空治理 | B | simulation_proxy |
| 毫米波通感实验站 | 26 GHz | 400 MHz | 35 dBm/sector | 15 m AGL | 25站/km2 | 密集热点、重点设施、活动安保 | B | simulation_proxy |

表中的中心频率用于把频段类别落实为可运行配置，不代表全国统一指配；带宽、功率、站高、密度、站间距和阵列均为首版工程代理值。正式项目应依据频率许可、产品手册、站址规划和现场测量创建新版本，不能直接覆盖旧版本。

## 4. 传播校准与兼容预设

`3GPP UMa` 和 `3GPP UMi street-canyon` 继续保留，用于传播场景校准。它们描述的是场景几何和统计建模条件，不是国内低空基站产品标准。`项目中间档`仅用于兼容旧实验和敏感性分析。

## 5. 城市匹配建议

| 城市或任务 | 优先预设 | 使用理由 |
| --- | --- | --- |
| 密集高层城区 | Sub-6 GHz低空宏站，必要时增加4.9 GHz或毫米波热点 | 高楼遮挡和多站干扰明显，需要较密覆盖与多站协同 |
| 普通城区与规则街区 | Sub-6 GHz低空宏站 | 容量和覆盖较平衡，适合验证切换与干扰 |
| 郊区与物流长航线 | 低频广域通信站加Sub-6 GHz热点 | 低频保障连续性，中频承担图传和容量 |
| 景区与重点设施 | 4.9 GHz通感实验站 | 适合研究通信、目标发现和轨迹管理的联合部署 |
| 港口与开阔水域 | Sub-6 GHz或4.9 GHz通感实验站 | 视距条件相对较好，可研究远距离覆盖和多目标场景 |

城市匹配只是实验设计建议。是否满足覆盖、SINR、速率或感知指标，仍需运行对应信道与系统模型后判断。

## 6. 当前能力边界

Sionna RT 根据几何、材料、天线、发射功率和接收网格计算传播路径与接收功率。当前工程由此生成宽带 RSS 和全频复用 SINR；它不会自动给出感知探测概率、距离精度、角度精度、虚警率或漏检率。`sensing_enabled` 是预设能力标签，真正的通感性能需要后续接入独立模型或实测数据。

主要依据包括工信部低空信息基础设施政策、3GPP TS 38.104、TS 23.256、TR 36.777、TR 38.901，以及中兴通讯和中信科移动公开的4.9 GHz与通感试验资料。正式引用时应记录文件版本和访问日期。
