# LAESim SceneGen UE host

Shared UE 4.27 host for scenes generated by the root `SceneGen` module.
It uses LAESim's canonical `Unreal/Plugins/AirSim` plugin, copied by
`SceneGen/scripts/SetupLAESim.ps1` after building LAESim.
The internal `WirelessCityFactory` module/project name is retained for asset compatibility.

From the LAESim root:

```powershell
& SceneGen/scripts/SetupLAESim.ps1
& SceneGen/scripts/BuildProject.ps1 -EngineRoot '<UE_4.27>'
& SceneGen/scripts/ImportExampleCity.ps1 -BundleRoot '<scene-run>' -EngineRoot '<UE_4.27>'
```

Generated content, copied plugins and compiled products are ignored.
See [SceneGen](../../../SceneGen/README.md) for configuration and coordinate contracts.
